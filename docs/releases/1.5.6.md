# Oxford to Notion v1.5.6

## 简体中文

- 右键点击最近导入的词条，可选择“重新导入此词”，无需再次输入。
- 菜单中的问号说明解释用途：更新已有词条，保留软件管理区域外的个人笔记。
- 保留原有点击打开 Notion 或 Oxford 的行为；导入时禁止重复触发。
- Windows 与 macOS ARM64 使用同一功能版本。

## English

- Right-click an imported word to reimport it without typing it again.
- Context-menu help explains that reimport updates an existing entry and preserves personal notes outside the app-managed Oxford section.
- Normal clicks still open the configured destination. Reimport is disabled while importing.
- Available for Windows and Apple silicon macOS.
