# Oxford to Notion v1.5.7

## 简体中文

- Windows 更新先验证新版并备份旧程序，替换失败时恢复旧文件；不替换个人配置或历史缓存。
- 后台线程复用连接，数据库字段缓存五分钟，减少重复检查请求；配置变化和请求失败后重新检查。
- Recent 会翻页补齐最多 100 条有效记录，最多请求 10 页，避免异常循环。
- Mac 使用系统界面字体及 PingFang 中文回退。
- 导入提速主要减少重复检查，实际速度仍受 Oxford 和 Notion 网络响应影响。

## English

- Windows updates stage and validate the new app, back up program files, and restore backups on replacement failure. Personal settings and history are preserved.
- Worker-local connections and five-minute database schema caching reduce repeated checks. Configuration changes and request failures invalidate cached checks.
- Recent fills up to 100 valid records across pages, with a ten-page bound and cursor-loop protection.
- macOS uses system UI fonts with PingFang Chinese fallback.
- Actual import speed still depends on Oxford and Notion response times.
