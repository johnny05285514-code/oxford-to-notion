# Oxford to Notion v1.5.5

## 简体中文

- 检测到旧版本时，显示当前版本和即将安装的版本。
- 自动沿用并锁定原安装目录，防止用户误选其他文件夹而保留两份软件。
- 安装前检查 Oxford to Notion 是否仍在运行；如仍在运行，会要求关闭后重试。
- 如果程序、图标或卸载程序无法替换，安装会明确停止，不会假报成功。
- 首次安装仍可正常选择安装目录；Notion 配置和最近导入记录继续保留。

## English

- Existing installations now show the installed and incoming versions.
- Updates reuse and lock the registered installation folder to prevent accidental side-by-side copies.
- Setup checks whether Oxford to Notion is still running and asks the user to close it before retrying.
- If the application, icon, or uninstaller cannot be replaced, setup stops instead of reporting success.
- First-time installs can still choose a folder. Existing Notion configuration and recent history remain preserved.
