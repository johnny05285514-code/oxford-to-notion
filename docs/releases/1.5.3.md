# Oxford to Notion v1.5.3

## 简体中文

- 设置新增“关于与更新”，显示实际安装的版本号。
- 点击检查更新、下载更新；校验通过后再打开安装程序。Windows 使用可见安装向导，Mac 使用 DMG 拖入 Applications / 替换。
- 中英文更新进度和错误提示；不会自动下载或静默安装。
- Windows 和 Apple 芯片 Mac 由同一流程构建，两份安装包及 SHA-256 文件验证成功后才一起发布。
- v1.5.2 用户需先手动安装本版本；个人 Notion 配置和历史保留。

## English

- Settings now includes About and updates with the installed version.
- Check and download updates in the app. Verified downloads open the visible Windows installer or the Mac DMG for Applications / Replace.
- Localized progress and failure messages; no automatic downloads or silent installation.
- Windows and Apple silicon macOS build together and publish only after both packages and SHA-256 files pass verification.
- Users on v1.5.2 need one manual installation. Existing Notion configuration and history are preserved.
